## 📌 Project at a Glance

**What:** Year 12 A-level students are building a real-world web application called **Calculus Explainer** — an interactive 3D visualization tool that helps students understand calculus concepts.

**Students:** 4-5 A-level students in roles as:

## 📚 The Product

### What Students Are Building

An interactive web app where students (A-level peers) can:

1. **Input a mathematical function** (e.g., "x²", "sin(x)")
2. **Visualize it in 3D** — Beautiful, interactive 3D graphs
3. **Explore derivatives** — See tangent lines and understand rates of change
4. **Explore integrals** — See areas under curves
5. **Get AI-powered explanations** — Claude AI explains concepts in plain English

### Real-World Use Case

Calculus is notoriously difficult for A-level students. This app helps students:
- See abstract concepts visually
- Experiment interactively
- Understand the "why," not just the "how"

### The Tech Stack (Industry-Standard)

- **Frontend:** React (Facebook's UI framework) + Three.js (professional 3D graphics)
- **Backend:** FastAPI (modern Python web framework)
- **AI:** Claude API (by Anthropic, cutting-edge AI)
- **Deployment:** Vercel + Railway (professional cloud hosting)
- **Version Control:** Git + GitHub (industry standard)

**Translation:** Students are using the exact same tools that professional software companies use. This isn't "educational software" — it's real development.

## 💼 Team Structure

### **3D Graphics Developer**
Learns Three.js (professional 3D graphics library). Builds beautiful, smooth 3D visualizations. By the end, understands 3D rendering pipelines.

### **Frontend Developer(s)**
Learns React (the most popular web framework). Builds the user interface, forms, and controls. By the end, understands modern web development.

### **Backend Developer**
Learns FastAPI and Python. Implements the math calculations (derivatives, integrals) and AI integration. By the end, understands API design and symbolic math.

### **DevOps Engineer**
Learns Git/GitHub workflows, CI/CD pipelines, and cloud deployment. Gets code from students' computers to live on the internet. By the end, understands professional DevOps practices.

**Each student specializes but learns all these technologies.**

## 🚀 Daily Standup & Agile

Each morning, students do a **10-minute standup**:
- What did you finish yesterday?
- What will you work on today?
- Are you blocked on anything?

**Why?** This is how professional teams stay in sync. It teaches communication and helps unblock each other quickly.

## 🤝 How Parents Can Help

1. **Create a distraction-free space** for focused work (coding requires concentration)
2. **Don't worry if they get frustrated** — debugging is part of learning; struggle builds resilience
3. **Show genuine interest** — Ask "What did you build today?" (not "Are you done?")
4. **Trust the process** — Two weeks feels short, but students accomplish a lot
