## 💡 Key Principles (The Philosophy)

This project is built on:

1. **Real-world learning** — Not classroom theory, but how actual software teams work
2. **Professional practices** — Git, code review, CI/CD, deployment
3. **Ship-based learning** — Students learn by building and deploying
4. **Team collaboration** — Different roles, code reviews, daily standups
5. **Ambitious but achievable** — Challenging enough to be interesting, scoped for 2 weeks
6. **Safety and support** — Comprehensive documentation, pairing, help available
