Core Concepts

📌 Variable

Declare with let (re-assignable) or const (fixed). Avoid the older var.

🏷️ Data Types

Primitives: number, string, boolean, null, undefined. Plus objects and arrays.

🧮 Function

A block of reusable code: function add(a, b) { … } or arrow form (a, b) => a + b.

🔁 Loop

Repeat work with for, for…of, or while. Or use array methods like forEach.

🔀 Conditional

Branch with if, else if, else, or the ternary cond ? a : b.

📋 Array

Ordered list of values: [1, 2, 3]. Comes with powerful methods like map, filter, reduce.

🗂️ Object

Key → value pairs: { name: "Sam", age: 25 }. The bread and butter of JS data structures.

🌐 DOM

The Document Object Model — the live tree of elements on a web page that JS can read and change.

Running JavaScript

JavaScript runs in two main places — start with whichever is closer to hand:

// 1. In the browser — open DevTools (F12) and use the Console tab
console.log("Hello from the browser!");

// 2. On your machine with Node.js
node hello.js
⚠️ Golden rule: Always use === for equality, not ==. The double-equals does type coercion that almost always surprises you.

EX 2

Variables & Template Literals

Get comfortable with let, const, and string interpolation.

  1. Declare a couple of values: 
    const name = "Ada";
let age = 36;
  2. Interpolate them with backticks: 
    console.log(`Hi ${name}, you are ${age} years old.`);
Hi Ada, you are 36 years old.
  3. Try changing age — it works. Try reassigning name — you'll get a TypeError.
EX 3

Functions & Arrows

Write the same function two ways — classic and arrow.

  1. Classic function declaration: 
    function add(a, b) {
  return a + b;
}
console.log(add(2, 3));  // 5
  2. Arrow equivalent — shorter, expression-bodied: 
    const add = (a, b) => a + b;
console.log(add(10, 7));  // 17
EX 4

Arrays: map & filter

Most real-world JS work involves transforming arrays. Skip the for-loop — use the built-in methods.

  1. Start with a list of numbers: 
    const nums = [1, 2, 3, 4, 5];
  2. Double every value with map: 
    const doubled = nums.map(n => n * 2);
console.log(doubled);  // [2, 4, 6, 8, 10]
  3. Keep only the evens with filter: 
    const evens = nums.filter(n => n % 2 === 0);
console.log(evens);  // [2, 4]

Key Takeaways

The core ideas to lock in before you close this page:

let & const, not var

Block-scoped, predictable, fewer footguns. Reach for const first; use let only when you reassign.

Always use ===

== does type coercion that almost always surprises. Stick with strict equality.

Arrow functions

Concise syntax for callbacks: x => x * 2. Mind the difference in this binding.

Array methods win

Prefer map, filter, reduce over manual for loops — clearer and immutable-friendly.

Template literals

Use backticks and ${expr} instead of string concatenation. Multi-line strings just work.

Async is everywhere

Get comfortable with Promises and async/await early — most real APIs are asynchronous.

Objects are references

=== on two objects checks identity, not contents. Copy with {...obj} when you need independence.

Open DevTools

Console, Sources (debugger), and Network are your daily tools. Learn them — you'll save hours.
