Core Concepts

📦 Variable

A named container for a value. Just assign with =: x = 5. No type declaration needed.

🏷️ Data Types

The basics: int, float, str, bool, plus collections like list, dict, tuple, set.

🧮 Function

A reusable block of code. Define one with def — pass it inputs, get back a result.

🔁 Loop

Do something repeatedly. for walks through a sequence; while runs as long as a condition is true.

🔀 Conditional

Branch your logic with if, elif, and else — choose which path to take.

📋 List

An ordered, mutable collection of items: [1, 2, 3]. Add, remove, sort, slice — lists do it all.

🗂️ Dictionary

Key → value pairs: {"name": "Ada"}. Fast lookup by key. Indispensable for structured data.

📦 Module

Reusable code in a file. Use import math to bring in the standard library, or install packages with pip.

Running Python Code

Two ways to run Python — pick whichever fits the moment:

# 1. Interactive REPL — try snippets instantly
python
>>> 2 + 2
4

# 2. Run a script file
python hello.py
⚠️ Golden rule: Indentation isn't cosmetic in Python — it's how blocks are defined. Pick 4 spaces and stick to it.

Hands-On Exercises

Open your terminal (or any online Python sandbox) and try these in order — each one builds on the last.

EX 1

Hello, Python

Confirm Python is installed and run your very first program.

  1. Check your Python version: 
    python --version
Python 3.12.0
  2. Start the interactive REPL and say hi: 
    python
>>> print("Hello, Python!")
Hello, Python!
  3. Press Ctrl+D (Mac/Linux) or Ctrl+Z then Enter (Windows) to exit.
EX 2

Variables & Strings

Get comfortable with values, types, and string formatting.

  1. Create a file called greet.py and add: 
    name = "Ada"
age = 36
print(f"Hi {name}, you are {age} years old.")
  2. Run it: 
    python greet.py
Hi Ada, you are 36 years old.
  3. Check the types you just used: 
    print(type(name), type(age))
<class 'str'> <class 'int'>
EX 3

Conditionals & Loops

Write a tiny FizzBuzz — print numbers 1–15, but say "Fizz" for multiples of 3 and "Buzz" for multiples of 5.

  1. Create fizzbuzz.py: 
    for i in range(1, 16):
    if i % 3 == 0 and i % 5 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
  2. Run it and watch the output: 
    python fizzbuzz.py
EX 4

Functions & Lists

Wrap reusable logic in a function and apply it to a list.

  1. In a new file avg.py, define a function and call it: 
    def average(numbers):
    return sum(numbers) / len(numbers)

scores = [82, 91, 76, 88, 95]
print(f"Average: {average(scores):.1f}")
  2. Run it: 
    python avg.py
Average: 86.4
  3. Try changing the list, or add a second function highest(numbers) that returns the max.

Key Takeaways

The core ideas to lock in before you close this page:

Indentation matters

Python uses indentation, not braces, to mark blocks. Pick 4 spaces and never mix tabs with spaces.

Dynamic typing

Variables don't declare a type — the value carries it. Use type() to check when you're unsure.

Use f-strings

f"Hello, {name}" is the modern way to format text. Cleaner than % or .format().

Prefer for over while

Iterate directly over collections (for item in list) rather than tracking indexes by hand.

Everything is an object

Functions, modules, even numbers — all are objects you can assign, pass, and inspect.

Read errors bottom-up

The last line of a traceback names the exception. The lines above show how Python got there.

Use the REPL

Type python in your terminal to experiment interactively. Faster than editing-and-running files.

Read the docs

Python's official docs are excellent. help(thing) works inside the REPL too.
