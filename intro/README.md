# Introduction to the Programme

Welcome! Before you dive into building your project, work through these four short guides. They will get you set up, oriented, and ready to collaborate like a real software team.

## Contents

| File | What it covers | Time |
|------|---------------|------|
| [01-welcome.md](./01-welcome.md) | What this programme is, what you'll build, how to pick your project | 15 min |
| [02-tools-and-setup.md](./02-tools-and-setup.md) | Installing VS Code, Node.js, Python, Git, and GitHub | 45–60 min |
| [03-working-as-a-team.md](./03-working-as-a-team.md) | Git workflow, pull requests, standups, and agile sprints | 20 min |
| [04-using-ai-as-a-developer.md](./04-using-ai-as-a-developer.md) | How to use GitHub Copilot and Claude effectively (and safely) | 20 min |

## How to use this section

1. Everyone on the team reads [01-welcome.md](./01-welcome.md) together on Day 1.
2. Each person follows [02-tools-and-setup.md](./02-tools-and-setup.md) on their own machine. Ask for help if you get stuck — setup problems are normal.
3. Read [03-working-as-a-team.md](./03-working-as-a-team.md) as a team and agree on your workflow before writing any code.
4. Read [04-using-ai-as-a-developer.md](./04-using-ai-as-a-developer.md) individually — you'll refer back to it throughout the two weeks.

Once you've done all four, head to [projects/README.md](../projects/README.md) to pick your project and get started.
